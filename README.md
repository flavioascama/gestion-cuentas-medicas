# Gestión de cuentas médicas

Sistema web para la orquestación, automatización y trazabilidad del ciclo de gestión de cuentas médicas en clínicas privadas.

Permite a la clínica registrar las cuentas médicas de sus pacientes asegurados, codificar las prestaciones, verificar la cobertura, generar y validar los lotes de facturación, enviarlos a las aseguradoras, atender las observaciones y glosas, y dar seguimiento a la liquidación, el pago y el cierre de cada cuenta. Cada operación queda registrada para su trazabilidad y un panel de control resume el estado del ciclo para la gerencia.

Incluye simuladores de las plataformas externas con las que se integra el sistema; todos los datos son ficticios.
